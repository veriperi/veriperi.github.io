content intelligence pipeline

type data engineering + genai pipeline
architecture bronze → silver → gold
sources itunes search api, rss feeds
output live streamlit dashboard

an end-to-end pipeline that ingests podcast and feed metadata via public apis, then enriches every record using an llm for content categorization, entity extraction, and quality scoring — before transforming it through a bronze → silver → gold architecture into analytics-ready tables.

orchestrated with airflow, modeled with dbt on postgresql, served through a fastapi layer, and surfaced on a live streamlit dashboard. fully containerized with docker.

field finding publisher-declared genres (e.g. "science") consistently didn't match what the llm found from actually reading episode content — publisher metadata alone turned out to be unreliable for classification.
